# 네이버 카페 홍보글 생성 스킬

## 개요
Premuto 앱의 새 기능을 네이버 카페(노견/반려동물 커뮤니티)에 홍보하는 글을 작성하고,
Playwright로 E2E 스크린샷을 촬영하여 함께 제공하는 워크플로우.

## 폴더 구조

```
C:/Users/cid41/Dev/premuto-promo/
  └── {기능명}-{YYYY-MM-DD}/
      ├── post.md          # 홍보글 본문
      ├── screenshots/     # Playwright 스크린샷
      │   ├── 01-{설명}.png
      │   ├── 02-{설명}.png
      │   └── ...
      └── notes.md         # 작성 메모 (선택)
```

## 글 작성 가이드라인

### 톤 & 스타일
- **1인칭 보호자 시점** — "저희 아기가...", "직접 만들었어요"
- **공감 우선** — 기능 설명 전에 왜 이 기능이 필요했는지 이야기
- **실제 경험 기반** — 10살 코카스파니엘(미모) 간병 경험에서 출발
- **따뜻한 마무리** — "모두 건강한 하루가 되길 바래요" 등
- **이모지 자연스럽게 사용** — 과하지 않게, 강조 포인트에만
- **반말 금지** — 존댓말(해요체) 사용
- **기술 용어 최소화** — 보호자가 이해할 수 있는 쉬운 표현

### 글 구조
```
제목: 노견용 건강관리앱 직접 만들었어요 #{번호}

1. 도입 (2-3줄)
   - 이전 글 언급 또는 근황
   - 미모 건강 상태 간단 공유

2. 기능 필요성 (3-5줄)
   - 실제 겪은 불편/필요
   - 수의사 선생님 피드백 등 에피소드

3. 기능 소개 (3-5줄)
   - 무엇을 할 수 있는지 간단히
   - 기술적 설명 X, 사용자 관점 설명 O
   - 스크린샷 삽입 위치 표시: [스크린샷: 01-{설명}.png]

4. 마무리 (2-3줄)
   - mimoharu.com 언급
   - 무료 사용 강조
   - 따뜻한 인사
```

### 주의사항
- **절대 과장하지 않기** — 실제로 있는 기능만 언급
- **다운로드/설치 언급 X** — 웹앱이므로 "접속해서 사용"
- **경쟁앱 비교 X** — 자기 앱 장점만 간결하게
- **광고 느낌 최소화** — 경험 공유 느낌으로

## 스크린샷 촬영 워크플로우

### 사전 준비
1. 로컬 dev 서버 실행 중인지 확인 (`npm run dev`)
2. 테스트 계정 로그인 상태 확인
3. 스크린샷 대상 기능의 시나리오 정리

### Playwright 스크린샷 촬영
Playwright MCP를 사용하여 스크린샷 촬영:

1. `browser_navigate` → mimoharu.com 또는 localhost:3000
2. 로그인 처리 (필요시)
3. 대상 기능 화면으로 이동
4. `browser_take_screenshot` → 각 단계별 캡처
5. 스크린샷 파일을 `screenshots/` 폴더에 저장

### 스크린샷 네이밍 규칙
- `01-메인화면.png` — 순번-설명 형식
- 한글 설명 사용, 공백 대신 하이픈
- 핵심 기능 화면 3~5장 정도가 적당
